# Myproject

## Snake Game

A simple browser-based Snake game built with HTML5 canvas and vanilla JavaScript.

### How to play

Open `index.html` in any web browser (or serve it with a static file server).

- **Arrow keys** or **WASD** — move the snake
- **Space** — pause/resume
- Eat the red food to grow and score points; avoid hitting the walls or yourself.
- Your best score is saved locally in your browser.
